# Probador de Estilos UI

Catálogo interactivo para elegir estilos visuales, layouts, técnicas de animación y patrones mobile **antes** de pedir un diseño, y así evitar el look genérico de "página hecha por IA".

## Qué incluye

- **22 estilos visuales**: minimalismo, neobrutalismo, swiss, editorial, glassmorphism, neumorphism, claymorphism, skeuomorfismo, Y2K, synthwave, terminal, memphis, orgánico, pixel art, art deco y más (incluye el "Genérico IA" como anti-ejemplo).
- **7 layouts**: clásico, bento grid, grid roto, split screen, masonry, full-screen hero, overlapping.
- **17 técnicas** que se combinan: parallax, smooth scroll, scroll snap, sticky, scrollytelling, scroll horizontal, aparición al scroll, split text, kinetic typography, microinteracciones, cursor personalizado, botones magnéticos, page transitions, marquee, 3D tilt, hover distortion y Lottie (simulado).
- **Modo app móvil**: Material 3 Expressive, Material You (con color semilla), Liquid Glass y Cupertino, más bottom sheet, swipe cards, haptics y navegación por gestos.
- Vista de **escritorio, tablet y móvil**, buscador, botón aleatorio y **generador de prompt** listo para copiar.
- La URL guarda la combinación elegida, así que se puede guardar o compartir.

## Cómo usarlo

1. Elige un estilo, un layout y las técnicas en el panel izquierdo.
2. Haz scroll y pasa el mouse sobre la vista previa para ver las técnicas en acción.
3. Presiona **Copiar prompt** y pégalo al pedir el diseño.

## Desplegar en GitHub Pages

1. Crea el repositorio `probador-estilos-ui` (público).
2. Sube el contenido de esta carpeta a la rama `main` (incluido `.nojekyll`).
3. Ve a **Settings → Pages**, en *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En uno o dos minutos queda en `https://<tu-usuario>.github.io/probador-estilos-ui/`.

## Tecnología

HTML, CSS y JavaScript sin dependencias ni build. Las fuentes se cargan desde Google Fonts. "Cumbre" es una marca ficticia usada solo como contenido de ejemplo.
